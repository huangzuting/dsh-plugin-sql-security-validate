## 插件名称

AI SQL 权限校验拦截插件

## 插件 ID

`dsh-plugin-sql-security-validate`

## 插件简介

DeepSeek Harness 通用 AI 数据库权限管控插件。拦截所有智能体生成的越权 SQL，
不静默改写、直接拒绝并返回明确权限原因，让 AI 自主修正查询逻辑。支持本地黑名单配置、
对接企业权限中台 OpenAPI，支持黑白双权限模式。支持普通拦截 / 企业级单调守卫严格拦截
双引擎。所有安全加固能力可配置开关、默认可卸载、轻量化通用，同时支持生产环境企业级
强安全加固。

## 亮点

- **不静默改写**：越权直接拒绝，返回结构化原因，杜绝「AI 以为数据完整」的幻觉答案。
- **完整资源解析**：表、字段、多表 JOIN、子查询、CTE、函数参数一次算清。
- **双权限模式**：黑名单（无策略即放行）/ 白名单模拟（无许可即禁止）。
- **双拦截引擎**：普通 `tools/pre-execute`，或企业级单调守卫 `ctx.tools.guard()`——
  拒绝后任何插件都无法推翻。
- **默认零绑架**：防卸载、强依赖校验、严格拦截全部默认关闭，装得上也卸得掉。
- **全量审计**：原始 SQL、结果、越权资源、策略来源、拦截模式、会话 ID 全记录，可落盘留痕。
- **通用不绑定业务**：只认工具名前缀与 SQL 参数键，适配任意 MCP 数据库服务。
